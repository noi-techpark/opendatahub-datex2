Dopo aver rigenerato il modello, nel file postgresContext.cs commentare le righe

protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
        => optionsBuilder.UseNpgsql("host=localhost;database=postgres;user Id=postgres;Password=pgpass;");

altrimenti la stringa di connessione impostata nel file config viene ignorata
